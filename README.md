# Vincent Low Portfolio
Product Designer & Frontend Engineer
I design and build digital products from user problems to working software.

Live site: [vincentlow.work](https://vincentlow.work)

## Built with

Next.js, React, TypeScript, CSS Modules, Tailwind CSS, and Vercel.

## Local development

```bash
npm install
npm run dev
```

Set `NEXT_PUBLIC_SITE_URL` to the production URL when deploying outside Vercel.
